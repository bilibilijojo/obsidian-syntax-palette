# Syntax Palette 0.5.11

This release changes iOS editor highlighting to use CodeMirror decorations when the host also exposes CSS Custom Highlights. The change addresses reports of native and Syntax Palette colors appearing together. It also updates reading-view token styling and refresh behavior.

The automated test suite and build checks passed. This change has not yet been verified on an iPhone: in particular, highlighting, editing, selection, and scrolling performance still require on-device testing. Mobile support remains experimental.

Requires Obsidian 1.14.5 or later. Install `main.js`, `manifest.json`, and `styles.css` together, retaining any existing `data.json`.
