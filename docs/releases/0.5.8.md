# Syntax Palette 0.5.8

This candidate fixes a mobile gesture conflict introduced by the shared-offset
editor scrolling in 0.5.7. Obsidian's ancestor swipe recognizer does not check
`defaultPrevented`; clipped code rows no longer look like native horizontal
scrollports, so a code drag can also activate a page/workspace swipe.

Touch-mode nowrap fenced rows now carry Obsidian's `data-ignore-swipe="true"`
opt-out. It is owned by CodeMirror's line decorations and disappears when
wrapping is enabled or the plugin is disabled. Desktop rows and ordinary prose
are unaffected. Native vertical panning and the shared-offset horizontal code
movement remain available. Workspace navigation swipes starting on these code
rows are intentionally excluded.

Regression coverage reads the installed Obsidian swipe recognizer at test time,
enables its mobile registration in an isolated desktop host, and supplies a page
translation callback. Removing the opt-out activates that callback; restoring
it leaves the page stationary while code moves. A separate vertical touch checks
that native page scrolling still works. Source tests cover decoration scope and
cleanup checks cover wrapping/plugin-disable transitions.

This is not an iOS native-navigation or physical iPhone test. Real-device
retesting is still required. Requires Obsidian 1.14.5 or later; install `main.js`,
`manifest.json`, and `styles.css`, retaining any existing `data.json`.
