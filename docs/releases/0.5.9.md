# Syntax Palette 0.5.9

This mobile candidate replaces per-fragment CSS displacement with one native
horizontal scroll container per fenced block when the host provides CodeMirror's
`BlockWrapper` API. The wrapper is created and managed by CodeMirror through
`EditorView.blockWrappers`; the plugin does not reparent editable DOM or replace
text with a widget. API availability was checked in Obsidian 1.15.0, the version
reported by the user. Hosts without this API keep the 0.5.8 shared-offset path.

Native block scrolling removes per-frame inherited CSS offset changes and the
extra position marks that were split by syntax tokens. The browser owns touch
panning and momentum. The plugin installs no touch listeners in this mode,
avoiding the main-thread wait caused by a non-passive touchmove listener.
Desktop row scrolling is unchanged. Width measurement, caret visibility,
virtualization offset restoration, wrapping and plugin cleanup are retained.

The 0.5.8 `data-ignore-swipe` navigation opt-out is present on the native wrapper
and code rows, including at block boundaries; vertical page panning remains
available. The reading-view gutter fix is unchanged.

The performance fixture compares 24, 46 and 120 logical code lines, including
many syntax tokens, over 60 offset updates. It records browser style/layout
metrics and mounted DOM counts rather than timing only the JS setter. The
baseline and new path use the same isolated macOS Obsidian 1.15.0 harness with
GPU disabled. These measurements do not establish iPhone FPS or native iOS
keyboard/selection behavior. On-device testing is still required.

Requires Obsidian 1.14.5 or later; the optimized mobile path uses the newer editor
API available in the checked 1.15.0 host. Install `main.js`, `manifest.json`, and
`styles.css`, retaining any existing `data.json`.
