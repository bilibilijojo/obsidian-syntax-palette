# Syntax Palette 0.5.6

This experimental candidate keeps the reading-view line-number gutter outside
the code scrollport, preventing horizontally scrolled text from painting over
the numbers. It also coalesces multiple editor touch updates into one update per
animation frame, while retaining shared row scrolling and momentum.

The gutter has a macOS WebKit pixel regression with a negative control; the
touch path has simulated event coverage. Neither proves real-device mobile
performance or interaction: verify iPhone scrolling, editing, selection, and
rotation before calling mobile support stable.

Requires Obsidian 1.14.5 or later. The standard installation files are
`main.js`, `manifest.json`, and `styles.css`; the Oniguruma runtime is embedded.
