# Syntax Palette 0.5.7

This experimental mobile candidate changes editor horizontal scrolling from
per-row native scroll synchronization to one shared CSS offset per fenced block
on supported coarse-pointer devices. CodeMirror owns the inline mark decorations;
the plugin does not reparent editable DOM, clone text, or change Markdown.

Clipped rows cannot pan or rubber-band independently, and late row scroll events
cannot overwrite the shared offset. Touch input remains coalesced once per frame,
with a single shared momentum calculation. Desktop native row scrolling remains
available. The reading-view gutter fix from 0.5.6 is retained.

Geometry measurements are queued outside CodeMirror's current measurement loop
so long-block viewport stabilization cannot strand a pending measurement.
Positioned mark fragments supply text width, avoiding inflated widths from the
host's unshifted syntax wrappers. Selection/caret measurements use the current
rendered offset, including after document offsets change.

Validation includes source regressions, macOS WKWebView geometry/event counts,
and isolated macOS Obsidian checks with coarse-pointer emulation and Chromium
protocol touch input on row 10. These are not iPhone frame-rate measurements.
The user reported low perceived frame rate and occasional row desynchronization
in 0.5.6 on iPhone 13 / iOS 18.7.8 with Low Power Mode off. This candidate still
requires on-device retesting of frame pacing, native selection, soft keyboards,
and rotation. No 60 FPS claim is made.

Requires Obsidian 1.14.5 or later. Install `main.js`, `manifest.json`, and
`styles.css`; the Oniguruma runtime is embedded. The package does not include
`data.json`, so existing settings can be retained.
