# Syntax Palette 0.5.2 — Initial public release

Make code blocks look the way you like.

Syntax Palette lets you choose code colors in Obsidian without changing your
whole app theme. This first public release includes:

- 39 color variants across 15 theme families, with independent light/dark choices.
- Syntax coloring for Python, JavaScript, TypeScript, JSON, Bash, HTML, and CSS.
- Optional code-block backgrounds, colored brackets, and line numbers.
- Editor wrapping controls and independent horizontal scrolling for long code lines.
- Local settings persistence without modifying the Markdown content of your notes.

## Installation

Download `main.js`, `manifest.json`, and `styles.css` from this release and copy
them into `.obsidian/plugins/syntax-palette/` in your vault. Reload Obsidian and
enable Syntax Palette under Settings → Community plugins.

The standard three files include the complete syntax runtime. No extra WASM
file is needed. Community Plugins installation will become available after the
initial directory review is completed; this release alone does not mean that
the listing has been approved.

## Compatibility

Requires Obsidian 1.14.5 or later on desktop. macOS has real-app verification;
Windows and Linux have not been tested on real systems. iOS, iPadOS, Android,
and pop-out windows are unsupported.
