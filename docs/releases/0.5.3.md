# Syntax Palette 0.5.3

This candidate enables installation on iOS, iPadOS, and Android, makes the
settings preview fit narrow screens, and fixes editor theme refresh in the
compatibility renderer used when CSS Custom Highlights are unavailable.

Mobile support is experimental and has not been validated in mobile Obsidian
on real devices. Touch scrolling, text selection, keyboard input, rotation,
and lifecycle behavior still require platform-specific acceptance. See the
[installation notes](../INSTALLATION.md) for a suggested test checklist.

Requires Obsidian 1.14.5 or later. The standard installation files are
`main.js`, `manifest.json`, and `styles.css`; the Oniguruma runtime is embedded.
