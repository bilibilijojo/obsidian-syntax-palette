# Syntax Palette 0.5.4

This experimental candidate adjusts editor code-block scrolling so native
overscroll can return from its edge without the synchronization controller
forcing the active row back to the boundary. It also avoids unnecessary
scroll-controller measurements when editor code wrapping is enabled.

iPhone touch responsiveness and edge bounce require real-device retesting;
the change does not establish that all reported mobile scrolling issues are
resolved. Mobile support remains experimental. See the
[installation notes](../INSTALLATION.md) for the wider mobile test checklist.

Requires Obsidian 1.14.5 or later. The standard installation files are
`main.js`, `manifest.json`, and `styles.css`; the Oniguruma runtime is embedded.
