# Syntax Palette 0.5.5

This experimental candidate drives visible rows of an editor code block from
the same horizontal touch gesture and applies shared momentum, addressing a
reported iPhone mismatch between the touched row and the rest of the block.
Vertical panning and pinch zoom remain browser gestures; long presses and text
selection are not intentionally intercepted.

Real iPhone testing is still required for synchronization, inertial scrolling,
vertical gestures, selection handles, keyboard editing, and rotation. Desktop
WebKit tests use synthetic touch events and do not establish iOS behavior. See
the [installation notes](../INSTALLATION.md) for the mobile test checklist.

Requires Obsidian 1.14.5 or later. The standard installation files are
`main.js`, `manifest.json`, and `styles.css`; the Oniguruma runtime is embedded.
