# Syntax Palette 0.5.12

- Replaced the four legacy VS Code palette choices with Light 2026 and Dark 2026 from VS Code 1.147.0. Saved VS Code choices migrate to the corresponding 2026 palette.
- Added JetBrains Light, Darcula, and Dark from IntelliJ IDEA 2026.1.5. The JetBrains preset uses Light and Dark by default. Darcula can be selected independently in the dark appearance menu.
- The new palettes use the existing fenced-code highlighting and optional theme background settings.

Requires Obsidian 1.14.5 or later. Update `main.js`, `manifest.json`, and `styles.css` together, and keep your existing `data.json`.
